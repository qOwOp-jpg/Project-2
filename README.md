# Project 2: The Not So Dark Side of the Moon

This is an interactive music player that combines moon data with audio visualization. The moon changes based on real data from the SunriseSunset.io API, while the circular spectrum and background respond to musicMain Features

- - View moon phases, illumination, and moonrise information using live API data.
- - Select different dates or explore the lunar cycle using the moon phase buttons.
- - Upload your own music and see the circular spectrum and background react to the sound.
- - Control music playback and adjust the audio reactivity.
- - Responsive layout for desktop and mobile

## How to Use

1. Open the website and select a date or moon phase to see how the moon changes.
2. To try the audio visualization, add a music file using "Add Files" and press play.
3. You can also adjust the audio reactivity slider to change the visual effects

## Project Files

- HTML, CSS, JavaScript, SunriseSunset.io API, and Web Audio API.
